# CampusHub API

## Project Description

CampusHub API is a simple backend application developed using FastAPI. It provides REST API endpoints to manage university data such as students, teachers, and courses.

## Features

* Home Endpoint
* Students Endpoint
* Teachers Endpoint
* Courses Endpoint
* Student Count
* Teacher Count
* Course Count

## Technologies Used

* Python
* FastAPI
* Uvicorn
* Git
* GitHub

## Run Project

```bash
python -m uvicorn app:app --reload
```
